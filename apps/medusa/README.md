# @mashoodwear/medusa

Medusa v2 **Iran Pack** for the Mashhoodwear monorepo (payments, shipping, phone OTP, IRT).

From repo root:

```bash
npm run install:all
npm run db:up
cp apps/medusa/.env.example apps/medusa/.env
npm run dev:medusa
```

- Store API: http://localhost:9000
- Admin: http://localhost:9000/app

See root [README.md](../../README.md) and `src/modules/IRAN-PACK.md`.
