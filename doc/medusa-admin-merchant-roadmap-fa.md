# نقشهٔ راه ادمین Medusa برای فروشگاه مشهود (فارسی)

> راهنمای عملی فروشنده از صفر تا آماده‌شدن ویترین.  
> آدرس پنل: `http://localhost:9000/app` (پروداکشن: همان URL ادمین Medusa روی سرور).  
> نام منوها با **زبان فارسی** پنل نوشته شده؛ اگر انگلیسی دیدی، از آواتار پایین → تنظیمات پروفایل → زبان را فارسی کن.

---

## ۰) دو پنل جدا — اشتباه نکن

| کار | کجا |
|-----|-----|
| محصول، سایز/رنگ، قیمت، موجودی، سفارش، مشتری، تخفیف، کانال فروش، منطقه، ارسال | **Medusa Admin** (`:9000/app`) |
| صفحات About / Contact / How to Buy، Lookbook، تنظیمات اینستاگرام/تلگرام | `/admin` ویترین مشهود (CMS) |

commerce فقط در Medusa ساخته می‌شود. پنل قدیمی Express دیگر منبع حقیقت کاتالوگ نیست.

---

## ۱) نقشهٔ منوی فارسی (سایدبار)

| منوی فارسی (تقریبی) | انگلیسی | کاربرد برای مشهود |
|---------------------|---------|-------------------|
| سفارش‌ها | Orders | پیگیری خرید، پرداخت، ارسال |
| محصولات | Products | ساخت لباس + وریانت سایز/رنگ |
| دسته‌بندی‌ها | Categories | پوشاک مردانه/زنانه و … |
| کالکشن‌ها | Collections | کالکشن برند + کاور |
| موجودی | Inventory | کنترل تعداد در انبار |
| مشتریان | Customers | خریدار + آدرس‌های ذخیره‌شده |
| پروموشن‌ها | Promotions | **کد تخفیف** |
| کمپین‌ها | Campaigns | سقف بودجه / کمپین تخفیف |
| لیست قیمت‌ها | Price Lists | حراج موقت / قیمت گروهی |
| تنظیمات | Settings | فروشگاه، منطقه، کانال، مکان انبار، ارسال |

داخل **تنظیمات** معمولاً این‌ها را می‌بینی:

| زیرمنو | کار |
|--------|-----|
| فروشگاه | نام فروشگاه، ارز پیش‌فرض، کانال پیش‌فرض |
| مناطق | ایران + ارز تومان/ریال |
| کانال‌های فروش | ویترین وب مشهود |
| مکان‌ها / Locations | مثلاً Iran Warehouse |
| پروفایل ارسال / گزینه‌های ارسال | هزینه و روش ارسال |
| مالیات | در ایران اغلب ساده نگه دارید مگر نیاز باشد |
| کلید API | برای توسعه‌دهنده |

---

## ۲) ترتیب صحیح از صفر (اول زیرساخت، بعد لباس)

این ترتیب را رعایت کن تا بعداً موجودی و checkout گیر نکند:

```text
۱ فروشگاه + ارز
→ ۲ منطقه ایران
→ ۳ مکان انبار (Location)
→ ۴ کانال فروش + وصل به انبار
→ ۵ روش ارسال
→ ۶ دسته‌بندی / کالکشن
→ ۷ محصول (با Manage inventory روشن از اول)
→ ۸ موجودی هر سایز
→ ۹ کد تخفیف
→ ۱۰ تست روی ویترین
```

### مرحله ۱ — فروشگاه

1. **تنظیمات → فروشگاه**
2. نام فروشگاه را درست کن
3. ارز پیش‌فرض را با پروژه هم‌خوان کن (IRT/تومان یا IRR طبق Iran Pack)
4. کانال فروش پیش‌فرض را یادداشت کن

### مرحله ۲ — منطقه

1. **تنظیمات → مناطق**
2. منطقهٔ ایران (یا همان که seed ساخته) را باز کن
3. کشور ایران و ارز را چک کن
4. اگر منطقه نداری: ایجاد → نام «ایران» → ارز مناسب

بدون منطقهٔ درست، قیمت و checkout روی ویترین می‌لنگد.

### مرحله ۳ — مکان انبار

1. **تنظیمات → مکان‌ها** (Locations / مکان انبار)
2. اگر نیست: ایجاد → مثلاً `Iran Warehouse`
3. آدرس ساده بگذار (حتی تستی)

بدون Location نمی‌توانی موجودی واقعی ثبت کنی.

### مرحله ۴ — کانال فروش

1. **تنظیمات → کانال‌های فروش**
2. کانال ویترین را باز کن (مثلاً Default / Web / Mashhoodwear)
3. **Location** را به این کانال وصل کن
4. بعداً هر محصول را به همین کانال اضافه کن تا در ویترین دیده شود

تمثیل: کانال فروش = ویترین مغازه؛ Location = انبار پشت مغازه. اگر انبار به ویترین وصل نباشد، لباس هست ولی فروخته نمی‌شود.

### مرحله ۵ — ارسال

1. از **تنظیمات → مکان‌ها** همان Location را باز کن
2. پروفایل/گزینهٔ ارسال را چک کن (پست، پیک، …)
3. قیمت ارسال را با منطقهٔ ایران هماهنگ کن

ویترین مشهود از Iran Pack برای آدرس ایران + روش ارسال استفاده می‌کند؛ اگر گزینهٔ ارسال نباشد، checkout می‌ماند.

---

## ۳) دسته‌بندی و کالکشن

### دسته‌بندی‌ها (Categories)

1. منو → **دسته‌بندی‌ها**
2. ایجاد → مثلاً «تی‌شرت»، «شلوار»
3. در ساخت محصول، دسته را انتخاب کن

### کالکشن‌ها (Collections)

1. منو → **کالکشن‌ها**
2. ایجاد → نام + (در این پروژه) تصویر کاور اگر ویجت فعال است
3. محصولات را به کالکشن وصل کن

---

## ۴) وارد کردن محصول لباس (مهم‌ترین بخش)

### ساخت محصول جدید

1. **محصولات → ایجاد**
2. عنوان فارسی لباس، توضیح، تصاویر
3. **گزینه‌ها (Options):**
   - `Size` یا `سایز` → مقادیر: S / M / L یا اسمال / مدیوم / لارج
   - در صورت نیاز `Color` یا `رنگ` → مشکی، سفید، …
4. Medusa از ترکیب گزینه‌ها **وریانت** می‌سازد (هر سایز/رنگ = یک وریانت)

### قیمت

- در همان ویزارد ساخت، یا بعداً روی محصول → Variants → **ویرایش قیمت‌ها**
- قیمت هر وریانت را جدا بگذار اگر لازم است
- Bulk Editor: روی سلول کلیک کن، عدد بزن، Tab، ذخیره

### کانال فروش روی محصول

- محصول را به کانال ویترین مشهود اضافه/فعال کن  
  (اگر فقط کانال دیگر فعال باشد، در سایت دیده نمی‌شود)

### وضعیت انتشار

- **پیش‌نویس** = فقط ادمین  
- **منتشرشده** = قابل فروش روی Store API / ویترین

### موجودی — حیاتی

روی **ساخت وریانت** یا ویزارد محصول:

- **Manage inventory / مدیریت موجودی را از همان اول روشن کن**

اگر وریانت را بدون آن بسازی و بعد روشن کنی، Medusa اغلب Inventory Item نمی‌سازد و صفحهٔ موجودی با نشانگر ممنوع قفل می‌شود (باگ شناخته‌شده).  
راه‌حل UI: آن وریانت را حذف کن و با Manage inventory روشن از نو بساز.

جزئیات بیشتر: بخش ۵.

---

## ۵) کنترل موجودی

### مسیر روزانه (پیشنهادی)

1. **محصولات** → لباس را باز کن  
2. منوی `⋯` کنار Variants → **ویرایش سطوح موجودی** / Edit stock levels  
3. در ستون **Iran Warehouse** عدد بزن → **ذخیره**

یا:

1. منو → **موجودی**  
2. آیتم مربوط به SKU/وریانت را باز کن  
3. برای Location عدد In stock را تنظیم کن

### معنی علامت‌ها

| چیزی که می‌بینی | معنی |
|-----------------|------|
| عدد مثل `10` | موجودی ثبت شده؛ با کلیک روی سلول قابل ویرایش |
| `-` + موس ممنوع | معمولاً Inventory Item به وریانت وصل نیست |
| Manage inventory خاموش | همیشه «موجود» فرض می‌شود (برای لباس واقعی توصیه نمی‌شود) |

### قانون طلایی مشهود

موجودی روی **وریانت** است نه روی خود محصول.  
تی‌شرت مشکی L جدا از تی‌شرت مشکی M موجودی دارد.

---

## ۶) کد تخفیف (پروموشن)

1. منو → **پروموشن‌ها**
2. **ایجاد**
3. قالب رایج برای شروع:
   - Percentage off order → مثلاً ۱۰٪ روی کل سفارش  
   - یا Amount off order → مبلغ ثابت
4. **کد** بگذار (مثلاً `MASHHOOD10`) — همین را مشتری در سبد می‌زند
5. محدودیت استفاده / تاریخ / شرایط محصول اگر لازم است
6. وضعیت **فعال** → ذخیره

خریدار کجا استفاده می‌کند؟ صفحهٔ **سبد خرید** ویترین مشهود → فرم کد تخفیف.

کمپین (**کمپین‌ها**) برای سقف بودجه یا گروه پروموشن است؛ برای یک کد ساده معمولاً همان پروموشن کافی است.

---

## ۷) لیست قیمت / حراج (اختیاری)

1. **لیست قیمت‌ها → ایجاد**
2. محصولات/وریانت‌ها + قیمت جدید + بازهٔ تاریخ
3. برای حراج فصلی بدون دست زدن به قیمت پایه

---

## ۸) سفارش، پرداخت، ارسال

1. **سفارش‌ها** → سفارش جدید را باز کن  
2. وضعیت پرداخت را ببین (Iran Pack / درگاه بانک)  
3. بعد از پرداخت موفق: Fulfillment / ارسال را از همان سفارش ثبت کن  
4. در صورت نیاز: مرجوعی / بازپرداخت از جزئیات سفارش

verify پرداخت فقط سمت Medusa است؛ در React کپی نمی‌شود.

---

## ۹) مشتریان و آدرس

1. **مشتریان** → مشتری را باز کن  
2. بخش **آدرس‌ها**: آدرس‌های ذخیره‌شده از ویترین (OTP/حساب) اینجاست  
3. سفارش‌های همان مشتری را از تب مرتبط ببین

ساخت اکانت خریدار از ویترین `/login` است، نه از پنل CMS مشهود.

---

## ۱۱) خطاهای پرتکرار (از تجربهٔ همین پروژه)

| مشکل | کار درست |
|------|----------|
| موجودی تایپ نمی‌شود / موس ممنوع | Manage inventory از اول؛ وریانت خراب را Delete و دوباره Create |
| لباس در سایت نیست | کانال فروش + Published + Sales Channel محصول |
| کد تخفیف کار نمی‌کند | کد در پروموشن‌ها فعال باشد؛ اعمال از Cart ویترین |
| قیمت عجیب | منطقه/ارز و Edit Prices وریانت را چک کن |
| ساخت محصول در `/admin` مشهود | نکن — فقط Medusa |
